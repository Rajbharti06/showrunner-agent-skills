## TikTok

**How people find content here (maintainer summary):** recommendation first, search growing; follower count matters less.

**Maintainer's view (an opinion, not a fact):** Fastest path to a first big view count. Check it is available and allowed in your country before you commit.

**Format fit, maintainer priors from 1 to 5 (opinions you can edit in `fit.json`):**

| Format | Fit |
|---|---|
| Short video | 5 |
| Long video | 2 |
| Carousel or document | 3 |
| Text | 1 |
| Live | 3 |

**What to measure:**

- Completion rate and average watch time
- Shares per view
- Profile visits per 1,000 views
